## Backend Project – 2.0

Alongside my Machine Learning projects, this repository also includes **2.0**, a backend application built with **FastAPI**.

The project was developed as a lightweight version of a larger fintech backend that I deployed separately. It allowed me to strengthen my understanding of backend software engineering by focusing on clean architecture, API development, and database interactions.

### Technologies

* Python
* FastAPI
* SQLAlchemy
* PostgreSQL
* Pydantic
* REST APIs

### Features

* RESTful API development
* CRUD operations
* Database integration using SQLAlchemy
* Request and response validation with Pydantic
* Modular project structure
* Error handling
* API documentation using Swagger/OpenAPI

### What I Learned

This project helped me gain practical experience in:

* Designing backend services
* Building maintainable API architectures
* Managing relational databases
* Structuring production-ready Python applications
* Writing clean and organized backend code

The experience gained while building this project also prepared me to work with backend technologies beyond Python. I am currently expanding these same software engineering principles into Java, with the goal of building scalable enterprise backend systems.
