# Machine Learning Portfolio

Welcome to my Machine Learning Portfolio.

This repository contains a collection of machine learning and deep learning projects that I completed while learning Artificial Intelligence through hands-on practice. Each project allowed me to explore different algorithms, datasets, and problem-solving approaches while strengthening my understanding of data science and predictive modeling.

My objective was not simply to learn the theory of machine learning, but to apply it by building real projects using Python and modern machine learning libraries.

# Projects Included

### Credit Risk Prediction
Predicting whether a customer is likely to default on a loan using supervised machine learning techniques.

### Breast Cancer Classification
Building classification models to predict whether a tumor is malignant or benign.

### Customer Churn Prediction
Predicting customer churn using historical telecom customer data.

### Employee Attrition
Analyzing employee data to predict attrition and identify influential features.

### Default Payment Prediction
Predicting credit card payment defaults using financial datasets.

### Medical Insurance Cost Prediction
Estimating medical insurance charges through regression models.

### Diabetes Progression Prediction
Predicting disease progression using healthcare datasets.

### Mall Customer Segmentation
Applying clustering algorithms to group customers based on purchasing behavior.

### Fashion MNIST Classification
Building neural networks to classify clothing images.

### Dogs vs Cats Classification
Training Convolutional Neural Networks (CNNs) to distinguish between images of dogs and cats.

### Turbofan Engine Prediction
Predictive maintenance project focused on estimating the remaining useful life of aircraft engines.

### Spam Detection
Classifying emails as spam or legitimate using machine learning techniques.

### Cybersecurity
Applying machine learning techniques to cybersecurity-related datasets and anomaly detection problems.
