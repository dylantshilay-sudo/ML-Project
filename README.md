### Technologies

* Python
* FastAPI
* SQLAlchemy
* PostgreSQL
* Pydantic
* REST APIs

### Features

* RESTful API development
* CRUD operations
* Database integration using SQLAlchemy
* Request and response validation with Pydantic
* Modular project structure
* Error handling
* API documentation using Swagger/OpenAPI
